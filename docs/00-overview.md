# 00 — Project Overview

## Vision

Build a **premium digital storefront for a single saree / Paithani shop**. This is NOT a
marketplace (not Meesho). There is one brand, one shop, one visual identity, one catalog,
one customer experience, and one admin/business dashboard.

The experience must communicate: **Heritage, Craftsmanship, Exclusivity, Trust, Luxury,
Authenticity, Modern shopping.**

It must not feel like a template, a college project, a Bootstrap site, or a basic CRUD app.

## Brand (temporary)

- **Name:** Vastraa Paithani
- **Tagline:** The Art of Timeless Paithani
- **Alternates:** "Woven Heritage. Timeless Elegance." / "Where Tradition Meets Royal Elegance."
- The name is a placeholder and can be replaced with the real shop name later.

## Positioning

A premium destination for authentic Paithani sarees, traditional silk sarees, and
handcrafted Maharashtrian weaving. Focus areas: authenticity, handloom craftsmanship,
Yeola heritage, quality, traditional motifs, premium silk, zari craftsmanship, wedding
and festive collections, personalized service.

**Honesty rule:** do not invent certifications or make unprovable claims about silk purity,
gold content, etc. Only show claims the real business can substantiate.

## Target customers

**Primary** — women shopping for wedding sarees, bridal Paithani, festive sarees,
Maharashtrian traditional sarees, premium silk sarees, gift sarees, family-occasion sarees.

**Secondary** — NRIs, wedding shoppers, premium fashion buyers, saree collectors, parents
buying wedding sarees, buyers seeking authentic Yeola Paithani.

## Final experience flow

Discovery flow: Beautiful Hero → Brand Story → Collections → Products → Craftsmanship →
Trust → Social Proof → Journal → Shop.

Purchase flow: Discover → Browse → Filter → Product → Wishlist/Bag → Checkout → Order → Track.

Admin flow: Dashboard → Products → Inventory → Orders → Customers → Content → Analytics.

## Tech direction

- Frontend: **React + Vite + Tailwind CSS** (JavaScript).
- Backend (planned): **Supabase** — Auth, PostgreSQL, Storage, RLS, Edge Functions.
- Deploy (planned): Frontend on Vercel / Cloudflare Pages, data + images on Supabase.

## Reference direction

Shubham Paithani is a **market/reference study** only (collection organization,
occasion-based shopping, price bands, heritage storytelling, artisan positioning,
editorial content). We do **not** clone its design, copy its text, or reproduce its
branding. Vastraa Paithani has its own identity and UI system.
