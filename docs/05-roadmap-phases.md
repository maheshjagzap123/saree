# 05 — Roadmap & Phases

## Build phases

| Phase | Focus | Deliverables |
|-------|-------|--------------|
| 1 | Brand & Design | Brand, logo, color system, typography, UI system, product card, buttons, header, footer |
| 2 | React Foundation | React project, routing, layout, components, responsive system, SEO framework |
| 3 | Supabase | Project, database, tables, storage, auth, RLS |
| 4 | Admin | Admin login, dashboard, product CRUD, image management, collections, categories, orders |
| 5 | Customer | Homepage, shop, collections, product details, search, filters, wishlist, cart |
| 6 | Checkout | Address, order creation, payment, confirmation, order history |
| 7 | Content | About, heritage, craftsmanship, journal, FAQ, contact |
| 8 | SEO | Metadata, canonical, sitemap, robots, schema, OpenGraph, image SEO, internal linking, blog SEO |
| 9 | Performance | Lighthouse, Core Web Vitals, mobile, image size, bundle size, accessibility |
| 10 | Deployment | Frontend → Vercel/Cloudflare, backend → Supabase, images → Storage, custom domain |

Phases 1-2 and most of 5 (public, mock-data) + 7 (partial) + 8 (framework) are addressed in
the current foundation. See `06-progress-and-status.md`.

## MVP vs V2

**MVP (must have):** Homepage, Shop, Collections, Product details, Search, Filters,
Wishlist, Cart, Checkout, Authentication, Orders, Admin, Product CRUD, Image upload,
Supabase, SEO, Responsive design.

**V2 (later):** Coupons, Reviews, Blog CMS, advanced analytics, WhatsApp automation,
product recommendations, abandoned cart, customer segmentation, gift cards, personal
styling consultation, appointment booking.

## Success criteria

- **Design:** premium, original, perfect on mobile, no template look.
- **Commerce:** browse, search, filter, wishlist, add to bag, checkout, view orders.
- **Admin:** manage products/images/collections/orders/customers, control homepage content.
- **Technical:** Supabase Auth, secure DB, RLS, storage policies, protected routes.
- **SEO:** metadata on every key page, sitemap, robots, canonicals, Product +
  Organization + LocalBusiness schema (where applicable), OpenGraph, optimized images,
  Search Console configured.
- **Performance:** responsive, good Lighthouse, good CWV, optimized images, fast navigation.

## Portfolio positioning (one-liner)

> Vastraa Paithani is a premium single-brand e-commerce platform for a traditional Paithani
> saree retailer. Built with React and Supabase, it combines an editorial luxury shopping
> experience with secure authentication, product management, inventory, orders, customer
> accounts, image storage, admin operations, analytics, and a complete technical SEO
> foundation.
