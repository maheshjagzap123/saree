# 09 — Image Prompt Pack (all 35 images)

Real imagery to replace the built-in SVG illustrations. **35 images total**, each with:
a short explanation (what it is + where it appears), the sizes, and a full ready-to-paste
"Create a Paithani image…" prompt.

## Sizes — read this first
ChatGPT / DALL·E only outputs **1024×1024**, **1024×1536** (portrait), or **1536×1024**
(landscape). For each image below:
- **ChatGPT size** = the option to pick when generating.
- **Final size** = resize/crop to this before using on the site.

Keep the ending line "No text, no watermark, no logo" in every prompt — it stops ChatGPT
from adding captions.
